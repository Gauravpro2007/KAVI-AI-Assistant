
# KAVI - Knowledgeable Artificial Virtual Intelligence

Stark-inspired AI desktop assistant built in Python.

## Features
- Voice Recognition & Text-to-Speech
- Time & Date
- Open Google, YouTube, GitHub
- Google Search & YouTube Search
- Rich Terminal UI
- Offline/Online toggle

## Tech Stack
Python, speech_recognition, pyttsx3, rich

## How to Run
```bash
pip install -r requirements.txt
python KAVI_FINAL.py
```

## Commands
- "open google"
- "open youtube"
- "open github"
- "what is the time"
- "search python tutorials"
- "play fav song"
- "exit / offline"
